# Spring Boot 4 notes

Things that work differently from Spring Boot 3 and cost time in this project. Each was hit while building Stage 1;
the "symptom" column is what you see when you get it wrong.

| Topic                                    | Boot 4.1 behaviour                                                                                                                                                                                                               | Symptom if done the Boot 3 way                        |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| Starters                                 | One starter per technology: `spring-boot-starter-webmvc`, `-kafka`, `-jdbc`, `-flyway`, `-validation`, `-actuator`.                                                                                                              | Missing auto-configuration; beans not created.        |
| Test slices                              | Each starter has a test module (`spring-boot-starter-webmvc-test`, ...). `@WebMvcTest` is `org.springframework.boot.webmvc.test.autoconfigure.WebMvcTest`.                                                                       | Import does not resolve.                              |
| `TestRestTemplate`                       | Not in `spring-boot-test` any more. The ITs use the JDK `java.net.http.HttpClient`.                                                                                                                                              | Class not found.                                      |
| Jackson 3                                | Packages `tools.jackson.*` (`JsonMapper`, `JsonNode`), annotations still `com.fasterxml.jackson.annotation`. `JsonNode.asText()` became `asString()`. Exceptions are unchecked (`JacksonException`).                             | Compile errors; Boot 3 examples do not paste.         |
| `@MockBean` / `@SpyBean`                 | Replaced by `@MockitoBean` / `@MockitoSpyBean` (`org.springframework.test.context.bean.override.mockito`).                                                                                                                       | Annotations removed.                                  |
| `@ConfigurationPropertiesScan` in slices | `@WebMvcTest` does not process it, so properties records are missing. This project uses `@EnableConfigurationProperties(...)` on a `@Configuration` class, which the slice test `@Import`s.                                      | `NoSuchBeanDefinitionException: IngestionProperties`. |
| Spying on `KafkaTemplate`                | Boot declares the bean as `KafkaTemplate<?, ?>`. A `@MockitoSpyBean KafkaTemplate<String, byte[]>` matches no bean. Declare the field as `KafkaTemplate<?, ?>` (see `PartialPublishFailureIT`).                                  | "No bean found" for the spy.                          |
| `FilterRegistrationBean`                 | Lives in `org.springframework.boot.web.servlet` (unchanged), but servlet autoconfig moved to `spring-boot-webmvc`/`-tomcat`.                                                                                                     | —                                                     |
| Testcontainers 2                         | Artifacts `testcontainers-kafka`, `testcontainers-postgresql`; classes `org.testcontainers.kafka.KafkaContainer`, `org.testcontainers.postgresql.PostgreSQLContainer` (no longer generic). `@ServiceConnection` works as before. | Old `org.testcontainers.containers.*` imports fail.   |
| Status 413                               | `HttpStatus.CONTENT_TOO_LARGE` (RFC 9110 name); `PAYLOAD_TOO_LARGE` is deprecated.                                                                                                                                               | Deprecation warning.                                  |
| Mockito agent                            | JDK 21+ warns when Mockito self-attaches. The service POMs pass Mockito to surefire and failsafe as `-javaagent:${org.mockito:mockito-core:jar}` (the path comes from `maven-dependency-plugin:properties`).                     | Warning on every test run.                            |

Versions are pinned by the Boot BOM; see [ADR-0001](../adr/0001-platform-versions.md).
